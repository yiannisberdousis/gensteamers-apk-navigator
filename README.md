# GenSTEAMers APK Navigator

## First team review draft — v09

Date: 30 September 2026

Open `index.html` in a browser. The same file is ready to serve as a static site, including on GitHub Pages. No build, installation, accounts, API keys or backend are required.

## What this draft includes

- Explore → Prepare → Choose → Reflect navigation, with back, forward and parent-section controls.
- The supplied Prompt Engineering Guide, organised into readable sections with its text, tables and images preserved.
- A download button for the original Word guide, embedded in the HTML.
- Four project entry pages with a brief overview where source material is available and a hand-off to the project's own navigator. No duplicate lesson plans, worksheets or project-resource pages.
- A two-question selector using documented learning focus and modular duration for Chatting with AI and Our Screen Time.
- The GenSTEAMers logo, palette and typography stack used by the Chatting with AI Teacher Navigator.
- General Assessment tips & guidance as one pending section, without a duplicate route to project assessment resources. Sharing results remains available.

## Known pending content

- Mapping Time and Monopoly: project descriptions and matching metadata are unavailable. They remain visible and are explicitly unassessed by the selector.
- Our Screen Time, Mapping Time and Monopoly: navigator URLs are pending. Only the supplied Chatting with AI URL is connected.
- Our Screen Time full-pathway duration: source timings are inconsistent; the full duration remains TBC. The selector uses the approximately four-hour modular duration.
- General assessment guidance and the scope/integration of the proposed assessment tool, reflection tool, sharing guidance, and other APK draft resources marked TBC.

The selector is guidance based on available source material, not an assessment or a validated suitability score. No new educational activities or assessment instruments have been authored for this draft.

## Review focus

1. Can a teacher find the relevant guide section or project without unnecessary steps?
2. Are project overviews, matching criteria and navigator destinations accurate?
3. Which TBC sections can be completed from existing project material?
4. Is the distinction between general assessment guidance and the project navigators clear?

## Packaging

`index.html` contains the styles, scripts, logo, guide images and original Word guide. No supporting asset folder is needed. Reading the guide and using internal navigation work offline; opening an external project navigator requires internet access.

Upload this folder's `index.html` as the site entry file. Keep the original numbered HTML versions separately as the version archive. This package contains no test scripts or local filesystem dependencies.

The original guide is intentionally downloadable by anyone with access to the published navigator. This draft has not been uploaded or published by the assistant.
